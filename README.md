# BetterAgent

致力于寻找一种搭建更好的Agent的方法。

## 核心理念

**Agent = 输入组织 + 约束设计 + 执行闭环 + 输出验收**

把 Agent 设计拆成四个可以填写、检查和改进的部分：

| 组成 | 要回答的问题 |
|---|---|
| 输入组织 | 要做什么？依据哪些信息？ |
| 约束设计 | 允许做什么？遵守哪些规则？最多投入多少资源？ |
| 执行闭环 | 如何采取行动，并根据结果调整下一步？ |
| 输出验收 | 交付什么？用什么证据判断已经完成？ |

**每一次改进，都从具体的失败出发，找到对应的设计环节，再通过实际结果验证。**

```text
发现问题 → 定位环节 → 修改设计 → 运行验证
```

公式的逐层展开与符号说明见 [00 · 导论：设计理念](./docs/00-导论.md)。
